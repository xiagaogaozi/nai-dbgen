# 召回与生图结果校验、纠错重试 · 0.2.42

预设编辑页新增「结果纠错重试次数」。召回、生图按各自使用的预设分别配置，随预设存储、导入导出。旧预设没有该字段时默认 3；0 表示不重试；3 表示首轮失败后最多再纠正 3 次，合计最多 4 轮结果。内置预设也明确携带 `retryCount: 3`。

## 解析与校验

- 扁平生图回文兼容字段名大小写、全角冒号和常见 Markdown 加粗。额外的 `生成点`、`notes` 等字段只作分界，不会拼进编号、尺寸或提示词；分析中的 Foreground / Middle ground / Background 分层内容保留。
- 每个扁平生图段必须有非空 `analysis`、`scene`，以及显式 `scene_uc`（可为空）。多图还须有合法 `slotid`。`size` 保持可选，提供时校验宽x高格式。
- 有角色时必须按角色成对输出 `char`、`char_uc`，两者条数一致，UC 可以显式为空。纯背景图按照原预设规则可以同时省略角色字段。
- 楼层写 slot 要求返回全部召回指定的编号，不接受重复、缺少或额外编号。外部写词接口保留已有的多张图返回行为，但每一张都必须通过字段校验。
- 召回必须返回非空位置数组，每个位置须有目标正文中的生成点文本，以及显式候选数组 `key`；没有候选可写 `[]`。某一项缺字段会报告该项路径，不会因其他项正常就忽略它。
- 旧 JSON 生图结果继续按 caption 树契约兼容，但在默认值归一化之前检查正负场景词、角色数组及配对，缺字段不再自动补空后通过。

## 重试流程

`application/preset-completion.js` 在同一阶段调用模型后运行结果校验。JSON 解析失败、必填字段缺失、格式错误和不可匹配的全部生成点都会进入纠错重试。

下一轮保留最初预设、上下文和参考图片，附上上一轮模型结果以及具体校验问题，例如「第 3 段的 char 与 char_uc 数量不一致」或「positions[0].key 缺失或不是数组」。要求重新返回完整结果。失败历史不逐轮累积，每轮只携带最近一次失败结果与问题。

传输错误、鉴权错误和 shujuku 未解析条件等宿主问题不会被当作字段问题交给模型纠错；既有网络退避仍由 LLM 网关负责。用户取消后停止继续请求。最终失败保留最后一次原文、问题列表、预设重试上限和实际调用次数。整个阶段通过后才保存结果；未通过时不写半套 slot，不触发 NovelAI。

入口覆盖楼层生成、工作台写词和 `NaiDbGen.generateSinglePrompt()`。调用方不需要增加参数。

## 验证范围

回归覆盖：默认/零/自定义次数、召回和生图独立配置、带问题纠错后成功、错误 JSON、空返回、全部次数失败、取消、额外字段隔离、缺失字段、角色 UC 配对、完整编号集合、多模态消息保留、预设编辑保存与重新打开，以及仓库导入导出往返。

使用用户给出的三图原文，验证编号分别读取为 1、2、3，并把第三段缺少角色 UC 的具体问题送入后续纠错请求。测试使用模型与图片接口替身，没有调用真实模型或 NovelAI。
